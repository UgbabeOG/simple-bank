# Simple Bank CLI

A lightweight, terminal-based banking application built in Python that simulates standard ATM operations like depositing, withdrawing, and checking balances.

## Features
- 💰 Real-time balance updates and tracking
- 🛡️ Robust user input validation (prevents text inputs from crashing the app)
- ❌ Prevent invalid operations (negative deposits or over-drafting)

## How to Run
Ensure you have Python 3 installed. Clone the repository and run:

```bash
python src/bank.py
```
